# DarlingOS-ZeroTwo

> 致敬《DARLING in the FRANXX》亲爱的 02
> 基于 Ubuntu 26.04 LTS 打造的定制桌面操作系统

---

## 项目定位

**DarlingOS** — 为国人打造的美观、易用、高性能 Linux 桌面系统

**代号**：ZeroTwo（02）

---

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 底层 | Ubuntu 26.04 LTS | 稳定长期支持版 |
| 显示协议 | Wayland | 现代显示服务器 |
| 登录管理器 | greetd | 轻量级 Wayland 登录器，macOS 风格 |
| 窗口管理器 | Hyprland | 平铺式 Wayland 合成器 |
| 桌面外壳 | Quickshell | QML 桌面框架 |
| 桌面环境 | DMS (DankMaterialShell) | Material Design 风格 |
| 启动器 | macOS 风格中文 Dock | 液态玻璃效果 |

---

## 设计风格

- 仿 macOS 液态玻璃质感
- Material Design 配色
- 中英双语支持
- 动画流畅、响应迅速
